# Lumen

> Cycle-aware productivity planner for ambitious women.

Free web tool that helps users schedule deep work, meetings, and creative time around the four hormonal phases of the menstrual cycle.

**Working name folder**: `cycle-flow` (will rename when domain decided).

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- Bun runtime
- lucide-react icons

## Getting Started

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) (or 3001 if port taken).

## Project structure

- `app/` — Next.js routes
- `components/` — React components
- `lib/` — Domain logic (cycle calculation, hormone curves, encyclopedia content, icons)
- `docs/reference/` — Archived strategy docs (PRD, market research) — reference only, not working plans
- `ROADMAP.md` — Working roadmap (Path C hybrid evolution)
